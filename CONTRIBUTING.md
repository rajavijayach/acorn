# Contributing to Acorn

Thank you for your interest in contributing.

## Before Contributing

Please read:

- Vision.md
- Manifest-Spec.md
- Template-Spec.md
- RFCs

## Principles

- Apps first
- Native macOS experience
- Apple Container only
- Simplicity over flexibility

## Good First Contributions

- Documentation improvements
- Template improvements
- UI polish
- Bug fixes

## Large Changes

Please open an issue and discuss the proposal before implementation.
