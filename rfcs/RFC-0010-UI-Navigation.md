# RFC-0010: UI Navigation

## Status
Accepted

## Purpose
Define primary application navigation.

## Sidebar Structure

### Home
Installed applications.

### Discover
Application catalog.

### Settings
Application settings.

## Navigation Principles

- Three top-level destinations only
- App-first terminology
- Progressive disclosure for advanced features

## App Details

Tabs:
- Overview
- Logs
- Manifest

## Non Goals

- Complex multi-panel workflows
- Infrastructure dashboards
- Container-centric views
