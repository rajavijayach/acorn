# RFC-0009: Template Catalog

## Status
Accepted

## Purpose
Define the curated application catalog.

## Version 1 Categories

### AI
- Ollama
- Open WebUI

### Databases
- PostgreSQL
- Redis

### Automation
- N8N

## Distribution

Templates are bundled inside the application.

No remote catalog exists in v0.1.

## Template Requirements

Every template must define:
- Metadata
- Installation settings
- Runtime configuration
- Upgrade strategy

## Future

Community catalogs may be supported in a future version.
