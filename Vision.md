# Acorn Vision

## Mission

Run self-hosted apps on macOS using Apple's native container runtime.

## Product Philosophy

Users install apps.

Users do not manage containers.

Containers are an implementation detail.

## Target Users

- Indie hackers
- Designers
- Students
- Developers who prefer GUI workflows

## Core Principles

### App First

Acorn should feel like an App Store for self-hosted software.

### Native

SwiftUI and Apple platform conventions first.

### Apple Container Only

Acorn is intentionally built for Apple Container.

### Open Source

Templates and core functionality should be community driven.

## Initial Scope

- App discovery
- Install apps
- Start and stop apps
- Logs
- Terminal access
- Manifest export and import

## Out of Scope

- Kubernetes
- Multi-host management
- User accounts
- Cloud services
- Plugin systems
