# UX Principles

## Apps First

Users install apps.

Users do not manage containers.

## Progressive Disclosure

Start simple.

Advanced controls remain available but hidden.

## Native macOS

Follow platform conventions.

Avoid web-style interfaces.

## Fast Feedback

Every action should provide immediate status and progress.

## Transparency

Users should be able to inspect generated manifests and runtime configuration.

## Friendly Defaults

Provide safe defaults for ports, storage, and resources.

## Learning Path

Beginner users should succeed quickly.

Advanced users should be able to understand what Acorn generated underneath.
